RFID

  • Radio-Frequency Identification
  • Data wordt opgeslagen op een sticker (transponder)
  • Elektromagnetische lezer leest de gegevens m.b.v. radiogolven
  • Makkelijk te verwerken
  • Unieke code: Electronic Product Code (EPC)
  • Werking via inductie (elektromagnetisch veld)
Communicatie tussen een RFID-tag en een transceiver (lezer / ondervrager) • De transceiver leest de chip uit welke verbonden is met een antenne. • Zo’n chip noemen we ook wel een transponder ofwel “het integrated circuit” • Deze chip bevat de unieke (beveiligings)code ofwel de Electronic Prouct Code (EPC) • Een goede werking door zowel de transceiver als de RFID-tag op dezelfde frequentie laten opereren • De tranceiver zend een radiosignaal via een bepaalde frequentie uit welke door de antenne in de RFID tag ontvangen wordt. • Het elektromagnetische veld zorgt ervoor dat de chip geactiveerd wordt en via zijn kleine antenne data terugstuurt naar de tranceiver De Electronic Product Code in de chip is meestal een 96-bits datastring • De eerste 8 bits van deze string vormen de header waarin het gebruikte protocol omschreven staat • De volgende 28-bits identificeren de- organisatie (id uitgegeven door GS1) welke de data op de tag beheerd • De volgende 24-bits vormen de “object-class en identificeert het type product • De laatste 38-bits vormen dan het unieke nummer voor tag

Electronic Product Code

96-bit datastring

Soorten RFID

  • Passief
    • Geen batterij, door inductie
    • Leesafstand: enkele cm (HF/NFC) tot ~10 m (UHF)
  • Semi-actief
    • Enkel zenden op antwoord van ontvangen signaal
  • Actief
    • Batterij: interval voor uitzenden
    • Leesafstand: 10-100 m
  • Chiploze tags
    • Geen ID
What is a chipless RFID tag? “Chipless RFID” is a generic term for systems that use RF energy to communicate data but don’t store a serial number in a silicon microchip in the transponder. Some chipless tags use plastic or conductive polymers instead of silicon-based microchips. Other chipless tags use materials that reflect back a portion of the radio waves beamed at them. A computer takes a snapshot of the waves beamed back and uses it like a fingerprint to identify the object with the tag. Companies are experimenting with embedding RF reflecting fibers in paper to prevent unauthorized photocopying of certain documents. There are inks that reflect back radio waves at certain frequencies, enabling farmers, for example, to tattoo a chipless RFID transponder on an animal for identification purposes.

BAN

  • Enkele meters
  • In of rond menselijk lichaam
  • Ster (met hub) of multihop
  • Nieuwe generatie Wireless Sensor Network (WSN)
Nieuwe generatie van Wireless Sensor Network (WSN) • Ontwikkeld door Zhong Yang • Monitoren van een persoon door gebruik van biomedische sensoren, bewegingsdetectoren en draadloze communicatietoestellen • Een mobiel toestel (die in contact staat met het internet), meestal een smartphone, verwerkt de gegevens van deze toestellen en stuurt deze door naar de gewenste platformen • Actuatoren (toestellen die invloed hebben op de omgeving) kunnen kunnen geïntegreerd worden in dit netwerk

  • Transmission Control Protocol
  • Connectiegestuurd protocol
  • Verbinding wordt opgebouwd en afgesloten
  • Verzonden data wordt bevestigd

  • Hypertext Transfer Protocol
  • Gebruikt voor communicatie tussen webserver en browser
  • Request / Response

  • GET, POST, PUT, PATCH, DELETE
  • HTTPS = HTTP + TLS (vroeger SSL)
  • HTTP/2 en HTTP/3 (over QUIC/UDP): sneller

MQTT

  • Message Queuing Telemetry Transport
  • Lightweight messaging protocol
  • M2M connection-oriented protocol
  • Verbinding blijft open tijdens gegevensoverdracht
  • Gebaseerd op TCP, huidige versie: MQTT 5
  • Broker verdeelt de berichten
  • Publish / subscribe op topics
  • Bericht: topic en inhoud (payload)

  • Hiërarchie met slashes: huis/woonkamer/temperatuur
  • + = één niveau: huis/+/temperatuur
  • # = alle onderliggende niveaus: huis/#

  • 0: At most once - fire and forget
  • 1: At least once - acknowledged delivery
  • 2: Exactly once - assured delivery
