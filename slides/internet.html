ARPAnet & TCP/IP

  • Voorloper van het internet
  • 1973: 37 netwerken
  • 1974: ARPA & Stanford ontwikkelen TCP/IP-protocol

Groei & Ontwikkeling

  • Toepassingen:
    • Inloggen op andere computers (telnet)
    • Elektronische post (e-mail)
    • Software verzenden/ontvangen (BBS, FTP)
    • Nieuwsgroepen
  • Groei aantal hosts:
    • 1983: 1.000 hosts
    • 1986: 5.000 hosts
    • 1987: 28.000 hosts
    • 1988: 60.000 hosts
    • 1989: 100.000 hosts

Uitbreiding van Netwerken

  • Nieuwe netwerken (1974-1989): MFEnet, SPAN, Usenet, Bitnet, Csnet, Eunet, Nlnet, Belnet
  • 1983: GSM & OSI-model
  • 1986: DNS
  • 1990: PDA

Ontstaan van het WWW

  • 1989: Robert Cailliau (BE) & Tim Berners-Lee (UK) > hypertextsysteem voor CERN-documentatie
  • 1990: Gestandaardiseerd hypertextsysteem, platformonafhankelijk, linken tussen bestanden
  • Projectnaam: WorldWideWeb
    Programmeertaal: Objective-C
    Webserver: NextCube

Doorbraak van het WWW

  • 1991: Code omgezet naar C (open-source, platformonafhankelijk)
  • 1992: Mosaic, eerste grafische webbrowser (NCSA)
NCSA: National Center for Supercomputing Applications, Mosaic doorbraak internet

Zoekmachines & Groei

  • 1993: Eerste zoekmachines
  • Lycos: 800.000 pagina's geïndexeerd
  • 1994: Yahoo en Altavista populair

Beveiliging & E-commerce

  • 1994: Ontwikkeling van SSL-protocol (beveiliging)
  • 1996: Eerste VoIP
  • Online bankieren, webwinkels, Pizza Hut eerste pizza online
  • 1999: Toename online bankieren, MP3, eerste sociale internetcommunity (ASL.to/Redbox)

World Wide Web (WWW)

  • Informatieruimte voor documenten en web resources
  • Unieke URI’s, hypertext links
  • Webbrowsers en webapplicaties

Web 1.0

  • Eerste ontwikkelfase (1989-2004)
  • Read-only, content uit filesysteem
  • Frames en tables
  • Server Side Includes, CGI (Perl, Python, Ruby)
  • Opvolgers: ColdFusion, PHP, ASP, JSP

Dynamische HTML & DOM

  • DHTML: combinatie van HTML, CSS en client-side scripts
  • Document Object Model (DOM) als structuur
  • AJAX: dynamische content via asynchrone JS en XML

Web 2.0

  • Participatief/Sociaal Web (2004-nu)
  • User-generated content, rijke gebruikerservaring
  • Social media, blogs, wikis, tagging, webapplicaties
  • Gepersonaliseerde reclame: gebruiker als product
  • Functionaliteit delen:
    • XML, RSS, Atom, JSON
    • Web Services: SOAP, WSDL
    • API’s: REST, GraphQL
  • Extensies, evolutie webstandaarden, frameworks (jQuery, Angular, React, Vue)
  • Cloud: IAAS, PAAS, SAAS

Web 3.0

  • Gedecentraliseerd ecosysteem (blockchain)
  • Betrouwbaarder, veiliger, opener, autonomer
  • Gebruiker baas over eigen data
  • Persoonlijke browse-ervaringen
  • Communicatie tussen machines en gebruikers
  • Semantisch web, AI, IoT, AR/VR, HCI
  • Smart contracts, dApps, NFT's, DeFi
  • Alomtegenwoordigheid (ubiquity)
